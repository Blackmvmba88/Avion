# Assets

Game assets including models, textures, shaders, and sounds.

## Structure

- `models/` - 3D models (GLTF/GLB format)
- `textures/` - Texture images
- `shaders/` - GLSL shader files
- `sounds/` - Audio files

## Asset Guidelines

- Use compressed textures where possible
- Keep model poly counts reasonable
- Optimize for web delivery
- Include attribution for third-party assets
